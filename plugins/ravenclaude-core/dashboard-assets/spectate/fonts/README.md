# Spectate vendored fonts (IBM Plex)

IBM Plex Sans + Mono woff2 files vendored for Harness Spectate (v0.2).

- Source: [IBM/plex](https://github.com/IBM/plex) release **v6.4.0**
- License: SIL Open Font License 1.1 — see `OFL.txt`
- Faces: Sans Regular / Medium / SemiBold; Mono Regular / Medium
- Do not replace with Inter, Roboto, system-ui, or a CDN load — local OFL files only

Loaded via `@font-face` in `../spectate.css` and `<link rel="preload">` in `../index.html`.
