# G1 — Claims table (FORGE format): recurring-defect hardening

Load-bearing facts the eventual hardening + build plan rests on. Each row is typed honestly:
**observation** = a dated incident already in the repo's committed record (grounded in the miners'
citations); **inference** = a claim about the future (a mechanism is feasible / would prevent a class)
that the FORGE panels + correlated-error critic must settle. Tier: **BLOCK** = the plan is wrong if
this is false; **WARN** = it weakens the plan but doesn't invalidate it. `settling-gate` = what would
confirm or falsify the row downstream.

Occurrences are carried forward from the three G1 miners only — none invented here.
